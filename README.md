# Microsoft_Copilot_Studio_Dio
## Desafio Dio - Suzano - Python Developer
Neste conteúdo aprendi a utilizar a plataforma Microsoft Copilot Studio para desenvolver meu próprio agente de IA voltado ao setor de viagens. Durante o processo apliquei estruturas de dados para a manipulação eficiente de variáveis como destinos e orçamentos e realizei ajustes finos na IA para elevar a precisão das respostas. Também implementei lógicas de conversação e fluxos condicionais que adicionam funcionalidades práticas e melhoram a interação personalizada com o usuário.
